# T03 Deal stages

## Task

Deal stages `LEAD → QUALIFIED → WON / LOST`; invalid transitions return 409.

## Acceptance criteria

- AC-1: Every deal has a `stage`, shown in deal responses. A new deal starts at `LEAD`.
